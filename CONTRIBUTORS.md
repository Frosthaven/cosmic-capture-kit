# Contributors

The public repository receives squashed export commits, so its git history
does not carry authorship. This file is the durable record of the people
who wrote the code.

- **Shane Stanley (Frosthaven)**: author and maintainer.
- **Brandon J. Wells** ([@dev-bjwells](https://github.com/dev-bjwells)):
  justfile compatibility fixes (X11 desktops, Linux Mint, older `just`
  releases), Windows developer tooling, and `.gitignore` fixes.

Mirror commits to the public repository carry a `Co-Authored-By` trailer for
each external contributor listed here. The export script refuses an export
when a human commit author is missing from this file.
