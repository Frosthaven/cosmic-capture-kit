# Settings: About

## About this software

At the top sits the app icon, the name, and the line "Desktop Screenshot &
Recorder". The small badge beside the icon credits Ashley Ball, who drew it, and
clicking it opens her site.

**Version**
:   Shows the version you are running, with a button beside it and a coloured
    caption underneath telling you where you stand.

| Caption | Button |
|---|---|
| Update status not checked yet. | Check for updates |
| Checking for updates... | Checking..., while it works |
| You have the latest version. | Check for updates |
| A failure reason, in amber | Check for updates |
| Version X.Y.Z is available. | See below |

When an update is available, what the button offers depends on your platform:

- **macOS and Windows**: **Install Update**, which downloads it, checks it, and
  installs it in one press.
- **Linux**: **Get Update**, which opens the project page. There is no one-press
  install on Linux, because you build it yourself.

Below the version you get **What's new**, with the release notes for that
version. They are shown even when you are up to date, because in that case they
are the notes for the version you are running.

**Notify me when an update is available**
:   **On by default.** This is the same setting as the **Don't remind me again**
    checkbox on the update prompt you get at launch, so unticking it there turns
    this off.

## Supporting this project

**Donations**
:   *Free forever. Donations help keep development going.*
:   A **Donate** button that opens PayPal. The Linux app is free software and
    always will be. Donating is optional and buys you nothing extra.

## The update prompt at launch

If an update is waiting when you launch, you get a small dialog titled **Update
available**: "There is a new update, would you like to update now? You can
always update from the About page in settings." It offers **Update Now** and
**Update Later**, and a **Don't remind me again** checkbox.

It will not go away if you click outside it. Choose one of the two buttons.
