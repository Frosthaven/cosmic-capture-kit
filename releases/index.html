    Release notes

    Every release, newest first. Each entry is the release's own notes, as written when it shipped.

    Downloads live on the releases page.

    v0.29.0

    Released 6 August 2026

    All Platforms:

    • OCR speaks more languages: text scanning now picks up any language pack installed on your system, and Settings gains a language dropdown to choose between them. The macOS and Windows builds now carry text scanning with English built in, so it works the moment you install.
    • The Health page names its tools: it now shows the resolved path of every external tool it found, each with a copy button, so "which ffmpeg is it actually using" is a glance instead of a guess.
    • Cloud sign-in opens by itself: connecting an account now launches your browser automatically, and the success page is delivered fully before the helper closes, so the tab confirms instead of erroring at the last step.
    • Recordings cannot stall on their own plumbing: an internal wait during recording could, in rare cases, block the write that fed it. It no longer can.
    • System tray counter for uploads: Now has crisper numbers for the percentage of the upload that is completed instead of being a bit blurry.
    • Packages list their locations: In the health panel, found packages now list their locations along with a copy button which can be useful for debugging.
    • Preview editor cloud storage UX: When uploading a file, the preview editor's upload meter and the system tray now keep you more informed. During the final handshake of a file, the meter will animate while the system tray becomes an hourglass. As soon as the cloud service finalizes the transaction, the meter turns green and the system tray becomes a checkmark.

    Linux:

    • There is now an AppImage, and it is the download to take. One file, no install step, and it carries its own ffmpeg and text-scanning engine, so recording and OCR work immediately with nothing else to set up. It also bundles the video libraries, which means GPU-accelerated recording on distros whose own ffmpeg is too old for it.
    • The AppImage updates itself: Settings, then About, checks for new releases and installs one in place. It keeps the filename and location you chose, so your capture shortcut, symlink or autostart entry keeps working afterwards. Put it somewhere you own, such as ~/.local/bin.
    • ARM builds: both the AppImage and the plain binary now ship for aarch64 alongside x86_64. That covers Asahi on Apple Silicon, Raspberry Pi 5 desktops and ARM laptops, which previously had to build from source.
    • The plain binary gained GPU recording and reaches further back: it now ships with hardware-accelerated recording enabled, and is built against an older system baseline, so it runs on distros it previously refused to start on.

    macOS:

    • The permissions window looks like the rest of the app: it now has the same frosted background as the other windows, and sizes itself correctly.

    Windows:

    • A paused recording is easier to spot: the tray icon's centre now stays red while paused, matching the recording dot, instead of blending into the surrounding brackets. The shape still tells the two apart.

    v0.28.1

    Released 5 August 2026

    All Platforms:

    • Cloud sign-in is more reliable: the sign-in helper that catches your browser's redirect now listens on both IPv4 and IPv6, so browsers that resolve localhost to IPv6 complete the connection instead of hanging.
    • Proton sign-in fallback: if your browser does not open on its own during Proton sign-in, the step now shows a link you can click or copy right away.

    Windows:

    • Cloud sign-ins open correctly: sign-in links were being cut short by how the browser was launched, so some connections could never complete. Links now open through the proper system call, intact.

    v0.28.0

    Released 5 August 2026

    All Platforms:

    • Proton Drive support: connect a Proton account under Settings -> Cloud Accounts and your captures upload end-to-end encrypted. Proton Drive supports uploading to your "My files" directory or to an album of your choice in the "Photos" section of your drive. This requires the official proton-drive CLI to be installed on your system.
    • Cloud folder browsing feels faster: The UI now immediately responds to interactions instead of waiting for cloud responses, making things a little snappier. An extra spinner has been placed into the file listing window for UX.
    • About page: the View All Patch Notes link now sits at the end of the patch notes themselves.

    Linux:

    • A packaged download: each release now ships the COSMIC/Wayland binary as a zip, so trying the app no longer requires building from source. It is on the release page's download table; unzip, chmod +x if needed, and run.

    v0.27.1

    Released 4 August 2026

    All Platforms:

    • Fixed Google Drive accounts silently breaking after about an hour: renewing the sign-in was missing a required credential, so the very first refresh after connecting always failed.
    • Cleaned up the cloud account setup screens to simplify the experience.
    • Redesigned the About page, which now includes a link to view all historical patch notes.

    v0.27.0

    Released 4 August 2026

    All Platforms:

    • Cloud accounts: connect Google Drive, OneDrive, and Dropbox under Settings -> Cloud Accounts. Sign-in happens in your own browser, tokens are kept in your system's keychain, and uploads go straight from your machine to your account. Nothing passes through anyone else's servers.
    • Upload from the preview editor: a new Upload action (Ctrl+U, Cmd+U on macOS) sends the capture to a cloud account and copies a link to it.
    • Live upload progress: a progress meter in the editor titlebar shows the upload as it happens, with cancel a click away. When it finishes, the meter turns success colored and stays until your next upload, and a trash button can take the upload back off the cloud if you change your mind.
    • Upload progress in the tray: while an upload runs, the tray and menu bar icon shows a clear, full-size progress counter.
    • YouTube uploads for self-configured setups: connect a YouTube account and upload videos with a title and visibility of your choice. This one needs your own (free) API credentials; the docs walk you through it step by step.
    • A real documentation site: guides for the capture tool, the preview editor, settings, the CLI, and cloud account setup now live at https://cck.thedragon.dev.
    • Recording toolbar stays quiet: toolbar tooltips no longer pop up over your content while a recording is running.

    Fixes:

    • Settings window could hang on close: closing settings right after cloud account work no longer wedges the window.

    v0.26.0

    Released 2 August 2026

    All Platforms:

    • Save now works like Save As: pressing Save opens a picker prefilled with where it would have saved, so you can always confirm or change the destination.
    • Better save experience: Check out the new options under _Settings -> Preview Editor. In the preview editor, you now have Save, Copy, Share, and Upload. Behaviors are intuitive and succinct.
    • Native share integration: On platforms that support it, the preview editor has a new "Share" file action available. This will launch your platform's native share widget.
    • Capture toolbar polish: Every option now has a tooltip, and the button used to capture has been changed to a checkmark to make it more obvious.
    • Toolbar group labels: each group of buttons in the editor's toolbar now has a small label describing what it does (and can be turned off in settings).
    • Curved arrows: arrows now have a third handle in the middle you can drag to bend them.
    • The selection tool is easier to use: selecting no longer looks like drawing, and pressing Escape now clears your selection.
    • Scanner can now be refreshed: The scanner mode now has a refresh button that you can use to freely re-scan what's in the selected region.

    Windows:

    • Fixed not being able to open the overlay editor after opening a dialog like Save/Settings.

    v0.25.1

    Released 1 August 2026

    All Platforms:

    • Instant capture: new shortcuts that save and copy without opening the editor.
    • Capture notifications: an editor-less capture says what it copied, and clicking it finds the file.
    • Shortcut conflicts: two capture shortcuts can no longer be given the same keys.
    • The editor opens faster: copying to the clipboard no longer holds up the editor while it opens.
    • Window captures are clean: a window capture can no longer contain a window you did not pick.
    • Failed recordings explain themselves: the reason is shown instead of a generic failure.
    • Edited images keep their capture info.
    • Scanner improvements: the scanner now reads what is on your screen right now instead of a copy taken when the capture started, so switching windows no longer gives you the old window's text. Your real screen stays visible while you scan, and a refresh button in the toolbar re-reads it whenever you want.

    Linux (COSMIC):

    • Recording starts right away on multi-GPU machines: it used to pause for several seconds at the start of every take before falling back.
    • Audio meters work: the microphone and system audio level indicators now show up correctly when a recording starts.

    macOS:

    • Permission prompts come to the front instead of opening behind other windows.
    • macOS 13 is now fully supported: screenshots and recordings work, not just an error message.
    • Failed captures explain themselves instead of the app silently closing.
    • Pressing a capture shortcut repeatedly no longer leaves old capture windows stuck open.

    Windows:

    • Captures work on scaled displays: above 100% scaling every capture failed instantly and silently. Fixed.
    • A failed capture says so instead of closing with nothing.
    • A stuck tray icon no longer swallows captures.

    v0.24.0

    Released 29 July 2026

    All Platforms:

    • Fixed a recording with no audio at all: on machines using the software recording path, two parts of the pipeline could collide and leave the recording silent.
    • A failed recording no longer breaks the next one: if a recording session died unexpectedly it could leave a stuck background process holding the file, and every later recording would fail until it was cleared by hand. That can no longer happen, and a session that does die is cleaned up automatically.
    • Interrupted recordings are kept, not lost: a recording cut short by a crash is recovered alongside your other captures instead of being discarded.
    • Recordings start faster: the encoder was being detected twice at the start of every recording, once needlessly.
    • More natural voice levels: the automatic gain now leaves more room above your speaking level, so louder syllables keep their punch instead of being flattened against the ceiling. Your level meter will read a little lower than before, which is the extra headroom.
    • Video editor settings: the Preview Editor settings page has a new Video Editor section, so save-on-copy, close-on-copy and copy-on-delete can differ between images and videos instead of sharing one set.
    • Small region selections work: dragging a very thin selection produced nothing at all, with no error. Fixed.
    • Crop button now reads "Apply Crop".

    Diagnostics:

    • Debug logging: Settings → Health → Debug has an opt-in "Enable Debug Logging" switch, off by default, with a button that opens the log folder. When something goes wrong, the log names it, which makes a bug report a single file instead of a conversation.

    Linux:

    • Folder buttons open the file manager: buttons that open a folder did nothing at all. Fixed.

    macOS:

    • Failures explain themselves: a capture that could not complete used to close with nothing and no message. It now says what happened and, where the fix is known, how to fix it.
    • Screen Recording permission: if the permission is missing or has been invalidated (which macOS often does after a system update), the app now says so and gives the steps to restore it.
    • Permissions are clearer: Accessibility is now labelled Recommended rather than Optional, explains what it is used for, and can be skipped without being asked again on every launch.
    • Manage Permissions has been added to the menu bar item, so the permissions window can be reopened whenever you want.
    • Stuck captures clean themselves up: a capture that never manages to open now exits on its own instead of lingering as an invisible process.

    Windows:

    • Nothing new this release.

    Known issues:

    • On Windows 10, the shaded overlay shown when selecting a capture area renders solid black instead of see-through, and frosted-glass window effects do not apply. Windows 11 is unaffected. Still under investigation.

    Note: Windows 10 is not officially supported, but effort is being made to ensure rudimentary compatibility at this time.

    v0.23.0

    Released 29 July 2026

    All Platforms:

    • Hand tool and a reorganized toolbar: Crop, Select, and Hand now sit together as one group. The hand tool (H, or hold middle click) pans the canvas without touching your annotations. The bottom bar gained a live info block showing the current resolution and original capture file size.
    • Zoom range increased: The preview editor zooms further than before, with the 100% detent still snapping exactly under your cursor.
    • Sharper icons everywhere: Every icon in the app is now drawn on whole pixels instead of being resampled onto a fractional grid. This leads to much cleaner icon display.
    • Crop framing: Entering crop now zooms out to leave a consistent margin around the image on all sides, so the handles are always reachable and there is room to expand the canvas outward.
    • Crop UX: The top toolbar items not related to crop now vanish while in a cropping session.
    • Annotations stay visible while cropping: Marks that fall outside the current crop rectangle are still drawn during a crop session, so you can see what you are about to cut. Covermarks and spotlight dimming are hidden during crop for usability, and return when you accept.
    • Live selection preview: Dragging a selection box in the canvas will now show a border around items that get included in the selection in real time as you continue dragging.
    • Covermarks cover expanded canvas: When you crop past the image bounds, the covermark pattern now fills the expanded area instead of stopping at the original edge.
    • Video share parity: The video editor's share actions now match the image editor's. Copied recordings get a proper name, and a share that cannot be baked is refused with a reason instead of silently producing the wrong file.
    • Fixed: The preview editor no longer crashes when zooming in quickly on a large capture with many annotations.

    Windows:

    • Windows 10 window controls: The minimize, restore, and close buttons now render on Windows 10. They were previously invisible while still being clickable.
    • Diagnostics report: Windows builds now write a small text report to %LOCALAPPDATA%\cosmic-capture-kit\logs describing the graphics adapter and window settings. It exists to track down a Windows 10 display problem and contains no screenshots, file names, or personal data. It will be removed once that issue is resolved.

    Known issues:

    • On Windows 10, the shaded overlay shown when selecting a capture area renders solid black instead of see-through, and frosted-glass window effects do not apply. Windows 11 is unaffected. This is under active investigation, and the diagnostics report above is part of tracking it down.

    Note: Windows 10 is not officially supported, but effort is being made to ensure rudimentary compatibility at this time.

    v0.22.0

    Released 28 July 2026

    All Platforms:

    • Crop tool: Crop any screenshot from the preview editor (press C or use the toolbar). Classic thirds-grid selection with draggable edges and corners, edge snapping with modifier override, and Enter to apply. Crop past the image bounds to expand the canvas: annotations work on the expanded space, and everything stays non-destructive until you save.
    • Companion colors: Press X to swap the active annotation color with its perfect companion color. Press X again to swap right back.
    • Multi-select groups: Selecting multiple annotations now wraps them in a group box you can drag, scale, and right-click as one. Scaling keeps every item's size, position, and overlap in perfect unison.
    • Tool shortcuts: Spotlight joined the highlighter group on U. The color picker moved to S, freeing C for the crop tool, so Photoshop muscle memory transfers.

    macOS:

    • Emoji picker: Press Ctrl+Cmd+Space while editing a text annotation to open the system emoji picker. Picking an emoji drops it right at your cursor.
    • Display consistency: Annotation strokes, text, and step markers now render at the same visual size on Retina and standard displays.

    v0.21.1

    Released 28 July 2026

    All Platforms:

    • Text annotations: Add text to any capture. Click to drop a box that grows as you type, or drag one out to a fixed width and let the text wrap inside it. Pick fonts, sizes, colors and outline weight. Dragged selection boxes match Photoshop's behavior for text vs paragraph bounds.
    • Emoji support: The text annotation tool also supports the full emoji space.
    • Save, Save As, Copy, Delete: Much clearer actions with failure notices when something goes wrong.
    • Tool shortcuts changed: Tool keys now follow Photoshop, so muscle memory transfers. Several tools are now grouped for cycling a single hotkey.
    • Multi-select: Shift-click to build a selection with any tool armed, and duplicate several annotations at once. Ctrl with a drawing tool lays a new shape over the top instead of grabbing what's underneath.
    • Step markers Now remembers the last used size.
    • Polish: Updated preview editor toolbar design.

    macOS:

    • Improved Encoder performance for recordings.

    v0.20.0

    Released 27 July 2026

    All Platforms:

    • Step markers: Number the steps in your screenshots. Click to drop a numbered circle — markers count 1, 2, 3… and renumber themselves when you delete one from the middle.
    • UI Updates: Reduced clutter in the window preview editor by grouping tools
    • Lighter on memory: Significant reductions across the app — capture sessions, the preview editor, and the tray icon all use less RAM.
    • Multiple capture: Improved support for multiple window preview editors open at once.

    Windows:

    • Fixes a bug where automatic update checks don't always trigger

    v0.19.2

    Released 27 July 2026

    All Platforms:

    • Pencil: Freehand drawing arrives to the image editor. Paired with an eraser tool, you can now mark up your images as you see fit!
    • Select with the pointer tool: click, Ctrl/Shift-click, or sweep a band to build a multi-selection, then move it as a group. Ctrl+A selects everything.
    • Place instantly: double-click any shape tool to drop a ready-made, pre-selected item in the center of the shot. Hold Ctrl while a tool is armed to draw on top of existing items instead of moving them.

    macOS & Windows:

    • The zoom slider's 100% tick now sits exactly on 100%, matching Linux.

    v0.18.0

    Released 26 July 2026

    All Platforms:

    • New: Image preview editor has been upgraded with the first round of annotation tools.
    • Annotate with arrows, boxes, box-highlights, and a dynamic highlighter that automatically stays readable over both dark and light backgrounds.
    • Redact sensitive details with pixelate or blur. Pixel size is based on what's visible - small text, faces, anything.
    • Dim & spotlight to darken the shot and draw the eye to what matters. Anything you spotlight stays fully visible, even through a pixelate or blur. Other highlight marks will also pierce the dimness.
    • Right click for extended control. Layer controls to bring to front, send to back, or move up/down. Update a selection's color, delete, or duplicate the item.

    v0.17.1

    Released 25 July 2026

    All Platforms: - The region selection box is now sleeker: thinner lines by default, shorter corner arms, and tighter gaps.

    Linux (COSMIC): - The Capture Active Monitor hotkey and --active-monitor CLI flag now capture immediately (as intended) instead of opening the monitor selector. - The preview editor now opens on the display you started the capture from, in both windowed and full-screen modes, matching macOS and Windows. - Removed deprecated settings to control float status, as this is now controlled through tiling window manager configs.

    Windows: - Recorded system audio now properly retains its loudness. - Muting system audio during a recording now properly works as expected instead of allowing light audio bleed through. - Overlays no longer flicker when being brought into view.

    v0.17.0

    Released 22 July 2026

    All Platforms: - New capture hotkeys: Capture Active Window and Capture Active Monitor instantly grab the focused window, or the monitor under it, with no picker. The old Start Capture action is now Capture All In One. All three hotkeys ship unbound by default, so you assign the keys you want. - The preview editor now opens on the display you started the capture from, even when the captured window is on another monitor. Switching from windowed to full-screen editing follows the monitor the editor is currently on. - Capturing a window that lives on another monitor now correctly grabs it in its active state when it is set to active in settings.

    macOS: - The preview editor's keyboard shortcuts (copy, save, save as, delete) now work the moment it opens, with no click needed first. - Under the AeroSpace tiling window manager, the preview editor and Settings window stay on the monitor you triggered from instead of being pulled onto another workspace. - Fixed the preview editor opening too small when the captured content was on a different-resolution display. - Capturing the active window now targets the focused window; onboarding requests the Accessibility permission it needs.

    Windows: - Capturing a glass or acrylic window now shows the desktop wallpaper behind it instead of the other windows that were there, matching macOS. - The Settings window now tiles correctly under the komorebi tiling window manager. - Restored the Mica material on focused Settings and preview title bars.

    v0.16.1

    Released 22 July 2026

    All Platforms: - The capture hotkey is now three separate actions: Capture All In One (the full picker overlay), Capture Active Window, and Capture Active Monitor. The two new ones capture instantly, with no picker. All default to unbound; set them in Settings > Keyboard Shortcuts. - Immediate captures follow your delivery settings exactly (copy to clipboard / open the preview editor) and open the editor on the correct monitor. - The settings window and preview editor now have proper titles ("Cosmic Capture Kit - Settings" / "Cosmic Capture Kit - Preview Editor"). If you float them in a tiling window manager by title, see the updated README rules; COSMIC float exceptions migrate automatically. - The settings window remembers its size between launches. - General settings: "Keep system tray icon" (renamed), with a new "Automatically start on login" toggle beneath it. - When recording system audio with a mic, ducking responds only to real speech from an enabled mic, never to background noise and never when the mic is off.

    macOS: - Keyboard shortcut fields show native modifier symbols (⌃⌥⇧⌘) universally. - Capturing a full-screen app window now grabs the window contents instead of the capture loading cover.

    Windows: - Windows now live-resizes: the settings window and preview editor re-layout and rescale during a resize drag, matching macOS. - Recording system audio keeps the dialog (center) channel on surround and spatial endpoints, and loud surround is smoothly limited instead of clipped. - A recording that hits an encoder stall now recovers and saves instead of hanging forever. - Single-window captures show the fullscreen loading cover with a cancel button, like macOS. - Capture selectors no longer appear in the taskbar; only the editor and settings do. - The system tray is on by default (with start-on-login); both can be switched off in General settings. - Fixed a crash that could kill the settings window as it opened, and Windows-key chords now display as "Win+...".

    Cosmic Desktop: - Loading indicators use a refreshed circular spinner. - The settings and preview windows now use frosted glass. - Single-window captures now reproduce the frosted glass backdrop, so a captured window matches how it looks on screen.

    v0.9.0

    Released 15 July 2026

    Cursor and window picker fixes: - The captured cursor is now taken at the right moment and placed correctly, including across multiple monitors. - A cursor indicator shows where the pointer is while you select a region or monitor, and the cursor is hidden while picking a window or during the countdown. - For a delayed capture, the cursor is captured at the moment the shot is taken. - Picking a window no longer briefly freezes the screen.

    Redesigned window border settings: - Separate Active and Inactive borders, each with its own color and width. - The active border follows your system accent color by default. - A new drop shadow toggle for captured windows.

    Other fixes: - Your settings no longer reset when the app updates.

    Released 12 July 2026

    • The about page of settings now carries update functionality, with patch notes and a notification toggle.
    • Video recording has been optimized at all scales. You can now record even on incredibly large studio displays.
    • Editing overlay has been enabled as an option if you prefer that for quick actions instead of opening a new window.
